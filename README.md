# 📡 API REST com Spring Boot

Este projeto é uma **API REST desenvolvida em Java usando o framework Spring Boot**, criada como estudo de backend para demonstrar conceitos de desenvolvimento de APIs, endpoints HTTP, controle de rotas, estrutura MVC e lógica de negócios em Java.

---

## 🧠 Visão Geral

A API foi construída para demonstrar funcionalidades básicas de um serviço backend, incluindo:

- Criação de rotas HTTP (GET, POST, PUT, DELETE)
- Estruturação de controllers, serviços e modelos
- Configuração de projeto com Spring Boot
- Organização de projeto e lógica de negócios

Este projeto é um exemplo prático de como construir uma API REST em Java, aplicando conceitos essenciais da arquitetura backend moderna usando Spring Boot. :contentReference[oaicite:1]{index=1}

| Tecnologia | Descrição |
